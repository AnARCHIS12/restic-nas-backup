# restic-nas-backup — Web GUI integration release notes

This update documents the optional web administration layer.

## Included

- existing restic-nas CLI remains the backup/recovery engine;
- separate Restic NAS Backup GUI project;
- documentation link from the CLI repository;
- GitHub Pages documentation link to the GUI;
- local-only GUI testing procedure.

The GUI is intentionally separate from the CLI so the command-line backup and recovery workflow remains usable without the web interface.
