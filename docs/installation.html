Installation

Set up a configurable Restic repository mirror to an SMB/CIFS NAS.

Principle The script stores no passwords in the repository. The SMB credentials file stays local on the server.

1. Prepare the NAS share

Create a share, for example Restic, with a NAS account that has read/write access.

2. Mount the NAS

sudo mkdir -p /mnt/restic
sudo mount -t cifs //NAS_IP/Restic /mnt/restic \
  -o credentials=/root/.smb-restic,vers=3.0,sec=ntlmssp
findmnt /mnt/restic

The last command must show the NAS CIFS share.

3. Install

git clone https://github.com/AnARCHIS12/restic-nas-backup.git
cd restic-nas-backup
sudo ./install.sh

4. Configure

sudo nano /etc/restic-nas-sync.conf
RESTIC_DATA="/srv/rest-server/data"
MOUNT_POINT="/mnt/restic"
NAS_IP="NAS_IP"
NAS_SHARE="Restic"
REST_SERVER_CONTAINER="rest-server"
RSYNC_OPTIONS="-aHAX --numeric-ids --delete-delay"

BACKUP_TIME="13:00"
BACKUP_DAYS="Mon..Sun"

BACKUP_TIME uses 24-hour HH:MM. BACKUP_DAYS can use expressions such as Mon..Sun or Mon,Wed,Fri.

5. Change the schedule

sudo restic-nas schedule
sudo restic-nas schedule set Mon..Sun 13:00
sudo restic-nas schedule set Mon,Wed,Fri 03:30

The command updates the local configuration, updates the systemd timer, reloads systemd and restarts the timer.

6. Test

sudo restic-nas backup
sudo journalctl -u restic-nas-sync.service -n 100 --no-pager
systemctl list-timers restic-nas-sync.timer
