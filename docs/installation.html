Installation

Set up a daily copy of a Restic repository to an SMB/CIFS NAS.

Principle The script stores no passwords in the repository. The SMB credentials file stays local on the server.

1. Prepare the NAS share

Create a share, for example Restic, with a NAS account that has read/write access.

2. Mount the NAS

sudo mkdir -p /mnt/restic

sudo mount -t cifs //NAS_IP/Restic /mnt/restic \
  -o credentials=/root/.smb-restic,vers=3.0,sec=ntlmssp

findmnt /mnt/restic

The last command must show the NAS CIFS share. Do not start a synchronization unless /mnt/restic is actually mounted.

3. Installer

git clone https://github.com/AnARCHIS12/restic-nas-backup.git
cd restic-nas-backup
sudo ./install.sh

4. Configurer

sudo nano /etc/restic-nas-sync.conf

Local example:

RESTIC_DATA="/srv/rest-server/data"
MOUNT_POINT="/mnt/restic"
NAS_SOURCE="//NAS_IP/Restic"
REST_SERVER_CONTAINER="rest-server"
RSYNC_OPTIONS="-aHAX --numeric-ids --delete-delay"

Set NAS_IP to your local address. Keep the real value out of a public repository if you want to keep your internal topology private.

5. Schedule at 13:00

The supplied timer runs the synchronization every day at 13:00, using the server timezone.

sudo systemctl daemon-reload
sudo systemctl enable --now restic-nas-sync.timer

systemctl list-timers restic-nas-sync.timer

6. Test immediately

sudo systemctl start restic-nas-sync.service
sudo journalctl -u restic-nas-sync.service -n 100 --no-pager
