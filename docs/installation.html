Installation

Mettre en place la copie quotidienne du repository Restic vers un NAS SMB/CIFS.

Principe Le script ne stocke aucun mot de passe dans le dépôt. Le fichier SMB reste local sur le serveur.

1. Préparer le partage NAS

Créez un partage, par exemple Restic, avec un compte NAS disposant de la lecture/écriture.

2. Monter le NAS

sudo mkdir -p /mnt/restic

sudo mount -t cifs //NAS_IP/Restic /mnt/restic \
  -o credentials=/root/.smb-restic,vers=3.0,sec=ntlmssp

findmnt /mnt/restic

La dernière commande doit afficher le partage CIFS du NAS. Ne lancez aucune synchronisation si /mnt/restic n'est pas réellement monté.

3. Installer

git clone https://github.com/AnARCHIS12/restic-nas-backup.git
cd restic-nas-backup
sudo ./install.sh

4. Configurer

sudo nano /etc/restic-nas-sync.conf

Exemple local :

RESTIC_DATA="/srv/rest-server/data"
MOUNT_POINT="/mnt/restic"
NAS_SOURCE="//NAS_IP/Restic"
REST_SERVER_CONTAINER="rest-server"
RSYNC_OPTIONS="-aHAX --numeric-ids --delete-delay"

Remplacez NAS_IP par votre adresse locale. Ne remettez pas cette valeur dans un dépôt public si vous souhaitez garder votre topologie interne privée.

5. Programmer à 13:00

Le timer fourni lance la synchronisation chaque jour à 13:00, selon le fuseau horaire du serveur.

sudo systemctl daemon-reload
sudo systemctl enable --now restic-nas-sync.timer

systemctl list-timers restic-nas-sync.timer

6. Tester immédiatement

sudo systemctl start restic-nas-sync.service
sudo journalctl -u restic-nas-sync.service -n 100 --no-pager
