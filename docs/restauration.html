Restoration

The NAS copy is a Restic repository, so it can be used directly as a restoration source.

1. Verify the NAS share

findmnt /mnt/restic

The result must show the NAS CIFS share.

2. List snapshots

sudo restic -r /mnt/restic snapshots

3. Restore to a working directory

sudo mkdir -p /restore
sudo restic -r /mnt/restic restore ID_DU_SNAPSHOT --target /restore

The restore is placed in /restore, allowing you to verify files before putting them back into production.

4. Provided helper

sudo /usr/local/sbin/restic-restore.sh

The helper lists the snapshots and asks which one to restore.

Important Copying the repository does not reinstall Debian, Docker or services by itself. It provides the Restic data and snapshots needed for restoration; rebuilding the system still depends on your installation procedure.
