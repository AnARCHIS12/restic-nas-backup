Restauration

La copie NAS est un repository Restic. Vous pouvez donc l'utiliser comme source de restauration.

1. Vérifier le partage NAS

findmnt /mnt/restic

Le résultat doit montrer le partage CIFS du NAS.

2. Lister les snapshots

sudo restic -r /mnt/restic snapshots

3. Restaurer vers un répertoire de travail

sudo mkdir -p /restore
sudo restic -r /mnt/restic restore ID_DU_SNAPSHOT --target /restore

La restauration est placée dans /restore, ce qui permet de vérifier les fichiers avant toute remise en production.

4. Script fourni

sudo /usr/local/sbin/restic-restore.sh

Le script liste les snapshots et demande lequel restaurer.

Important La copie du repository ne réinstalle pas Debian, Docker ou les services à elle seule. Elle fournit les données et snapshots Restic nécessaires à une restauration ; la reconstruction du système dépend ensuite de votre procédure d'installation.
